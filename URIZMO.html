🔗 SQL JOIN Clause Visualizer

Used to combine rows from two or more tables based on a related column between them[cite: 25].

INNER JOIN

Returns only rows that have matching values in both tables[cite: 26].

SELECT * FROM A JOIN B ON A.id = B.id;

LEFT JOIN

Retrieves all rows from left table and matching rows from right[cite: 27].

SELECT * FROM A LEFT JOIN B ON A.id = B.id;

RIGHT JOIN

Retrieves all rows from right table and matching rows from left[cite: 28].

SELECT * FROM A RIGHT JOIN B ON A.id = B.id;

FULL JOIN

Combines results of both LEFT and RIGHT joins, returning all rows[cite: 29].

SELECT * FROM A FULL JOIN B ON A.id = B.id;

📅 Date Arithmetic & Formatting

  • CURDATE(): Returns current system date in YYYY-MM-DD format[cite: 3].
  • DATE_ADD(): Adds intervals like days/weeks/months[cite: 4].
  • DATEDIFF vs TIMESTAMPDIFF: DATEDIFF computes total days[cite: 6]; TIMESTAMPDIFF allows flexible units[cite: 6].
  • DATE_FORMAT(): Formats dates using string flags[cite: 7].
